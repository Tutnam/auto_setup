# 🚀 Auto Setup - Автоматическая настройка системы

Комплексное решение для автоматической настройки CachyOS/Arch Linux системы с установкой пакетов и настройкой Samba сервера.

## 🌟 Основные возможности

- 🔐 **Модель привилегий Linux** - запуск через `pkexec` или `sudo` без лишних запросов паролей
- 📦 **Автоматическая установка пакетов** - через paru (AUR и официальные репозитории)
- 🖥️ **Настройка Samba сервера** - полная автоматизация от А до Я
- 🧪 **Тестирование работоспособности** - проверка всех компонентов
- 📊 **Детальная отчётность** - прогресс каждого шага
- 🛡️ **Безопасность** - разделение привилегий, пароли не хранятся, временные файлы очищаются
- ⚙️ **Поддержка переменных окружения** - `SAMBA_PASSWORD` для автоматизации настройки Samba

## 🎯 Быстрый старт

### Полная автоматическая настройка
```bash
# Клонируем репозиторий
git clone <repository-url> auto_setup
cd auto_setup

# Запускаем полную настройку (скрипт сам запросит права через pkexec / sudo):
python3 main.py

# Или напрямую с правами суперпользователя:
pkexec python3 main.py
# или
sudo python3 main.py
```

**Это всё!** Скрипт автоматически:
1. Установит все необходимые пакеты
2. Настроит Samba сервер
3. Протестирует работоспособность

## 🔧 Компоненты системы

### 1. 🌟 main.py - Главный оркестратор
**Основной скрипт для запуска всей настройки**

**Что делает:**
- Координирует весь процесс настройки
- Запрашивает пароль только один раз
- Последовательно выполняет установку пакетов и настройку Samba
- Предоставляет детальные отчёты

**Использование:**
```bash
pkexec python3 main.py
# или
sudo python3 main.py
```

[📖 Подробная документация](README_main.md)

### 2. 📦 install.py - Установщик пакетов
**Автоматическая установка необходимых пакетов**

**Возможности:**
- Установка paru (AUR helper) при отсутствии
- Установка пакетов через paru (официальные репозитории + AUR)
- Retry механизм для проблемных пакетов
- Обработка тайм-аутов
- Безопасное разделение привилегий

**Самостоятельное использование:**
```bash
pkexec python3 code/install.py
# или
sudo python3 code/install.py
```

### 3. 🖥️ samba_auto_setup.py - Настройка Samba
**Полная автоматизация настройки Samba сервера**

**Возможности:**
- Настройка прав доступа
- Конфигурация smb.conf (атомарная запись)
- Управление пользователями
- Запуск служб
- Настройка файрвола
- Тестирование работоспособности

**Самостоятельное использование:**
```bash
pkexec python3 code/samba_auto_setup.py
# или
sudo python3 code/samba_auto_setup.py
```

[📖 Подробная документация](code/README_samba.md)

### 4. 🧪 test_samba.py - Тестирование
**Независимая проверка работы Samba сервера**

**Что тестирует:**
- Статус служб (smb, nmb)
- Конфигурацию (testparm)
- Подключение к серверу
- Настройки файрвола

**Использование:**
```bash
python3 code/test_samba.py
```

## 🎛️ Настройка под свои нужды

### Изменение списков пакетов

Отредактируйте файл `code/install.py`:

```python
# Пакеты для установки через paru (официальные репозитории + AUR)
PARU_PACKAGES = [
    'google-chrome',
    'telegram-desktop',
    'visual-studio-code-bin',
    # Добавьте свои пакеты здесь
]
```

### Настройка Samba ресурсов

Отредактируйте конфигурацию в `code/samba_auto_setup.py` в функции `step_2_configure_smb()`:

```python
[shared]
    comment = Public Folder
    path = /home/boss/Загрузки/    # Измените путь
    # ... другие настройки
```

## 🛠️ Устранение неполадок

### Общие проблемы

#### Нет прав доступа
```bash
❌ Этот скрипт требует прав суперпользователя
```
**Решение:** Запустите с `sudo`

#### Ошибка импорта
```bash
❌ No module named 'install'
```
**Решение:** Убедитесь что запускаете из корневой папки проекта

#### Проблемы с сетью
```bash
❌ Ошибка загрузки пакетов
```
**Решение:** Проверьте интернет соединение, перезапустите скрипт

### Проверка статуса

```bash
# Проверка Samba
sudo systemctl status smb nmb
sudo testparm

# Проверка установленных пакетов  
yay -Q | grep -E "(chrome|yandex|samba)"

# Полное тестирование
python3 code/test_samba.py
```
