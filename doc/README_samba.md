# Автоматическая настройка Samba сервера

## Описание

Скрипт `samba_auto_setup.py` автоматизирует все действия по настройке Samba сервера из файла `samba.py`. 

## Возможности

✅ **Единый запрос пароля** - пароль root запрашивается только один раз в начале  
✅ **Автоматическая настройка прав** - устанавливает правильные права доступа  
✅ **Конфигурация smb.conf** - создаёт полную конфигурацию с резервной копией  
✅ **Управление пользователями** - добавляет пользователя в Samba  
✅ **Управление службами** - запускает и настраивает автозапуск служб  
✅ **Тестирование** - проверяет работоспособность сервера  
✅ **Настройка файрвола** - автоматически настраивает UFW  
✅ **Создание директорий** - создаёт необходимые папки  

## Использование

```bash
# Запуск скрипта автонастройки
python3 code/samba_auto_setup.py

# или
./code/samba_auto_setup.py

# Тестирование работы Samba после настройки
python3 code/test_samba.py

# или
./code/test_samba.py
```

## Что делает скрипт

1. **Запрашивает пароль root** один раз в начале
2. **Создаёт директории** для общих ресурсов
3. **Устанавливает права** на `/var/lib/samba/usershares`
4. **Настраивает smb.conf** с конфигурацией из оригинального файла
5. **Добавляет пользователя** в Samba (запросит пароль для Samba)
6. **Запускает службы** smb и nmb
7. **Проверяет статус** служб
8. **Тестирует подключение** к серверу
9. **Настраивает файрвол** UFW (если установлен)

## Настраиваемые ресурсы

Скрипт создаёт следующие общие ресурсы:

- **shared** - `/home/boss/Загрузки/` (публичная папка)
- **games** - `/mnt/aee8e7a9-5710-4dbb-bb8e-982c833a085f` (игры)
- **home2** - `/mnt/Home2` (дополнительное хранилище)

## Требования

- Python 3.6+
- Права sudo
- Установленный пакет samba
- Установленный пакет samba-client

## Установка зависимостей

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install samba samba-client

# Arch Linux
sudo pacman -S samba

# CentOS/RHEL
sudo yum install samba samba-client
```

## Безопасность

- Пароль root передаётся через stdin и не сохраняется
- Создаётся резервная копия оригинального smb.conf
- Все операции логируются в консоль

## Устранение неполадок

### Ошибка "Служба не запустилась"
```bash
# Проверьте статус вручную
sudo systemctl status smb
sudo systemctl status nmb

# Проверьте конфигурацию
sudo testparm /etc/samba/smb.conf
```

### Ошибка подключения
```bash
# Проверьте файрвол
sudo ufw status
sudo iptables -L

# Проверьте сетевые порты
ss -tlnp | grep -E "(445|139|137|138)"

# Проверьте IP адрес вручную
ip route get 1.1.1.1 | awk '{print $7}'  # Arch Linux/CachyOS
hostname -I  # Ubuntu/Debian
```

### Восстановление конфигурации
```bash
# Восстановить из резервной копии
sudo cp /etc/samba/smb.conf.backup /etc/samba/smb.conf
sudo systemctl restart smb nmb
```
