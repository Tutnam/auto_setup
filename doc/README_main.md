# 🌟 Главный скрипт автоматической настройки системы

## Описание

`main.py` - это центральный скрипт, который координирует весь процесс автоматической настройки системы. Он объединяет установку пакетов и настройку Samba сервера в единый автоматизированный процесс.

## ✨ Основные возможности

- 🔐 **Модель привилегий Linux** - запуск через `pkexec` или `sudo` (пароль запрашивается доверенной подсистемой ОС)
- 📦 **Автоматическая установка пакетов** - использует paru (AUR и официальные репозитории) для установки пакетов
- 🖥️ **Настройка Samba сервера** - использует samba_auto_setup.py для полной настройки
- 🔄 **Координация процесса** - управляет последовательностью выполнения задач
- 📊 **Детальная отчётность** - показывает прогресс каждого шага
- 🛡️ **Обработка ошибок** - продолжает работу при частичных сбоях

## 🚀 Использование

### 🚀 Быстрый запуск

Скрипт поддерживает **прозрачное автоповышение привилегий**: при обычном запуске он сам запрашивает права суперпользователя через `pkexec` (графический диалог Polkit), а при его отсутствии или отказе переключается на `sudo` в терминале.

```bash
# Обычный запуск (автоматический запрос прав):
python3 main.py

# Либо прямой запуск с повышенными привилегиями:
pkexec python3 main.py
# или
sudo python3 main.py
```

Для подавления автоповышения (в CI/CD или скриптах автоматизации):
```bash
python3 main.py --no-escalate
# или через переменную окружения:
AUTO_SETUP_NO_ESCALATE=1 python3 main.py
```

### 🔐 Использование переменной окружения для Samba

Для тихой настройки Samba без интерактивного ввода пароля пользователя Samba:

```bash
# Запустить с сохранением переменной:
SAMBA_PASSWORD="your_samba_password" sudo -E python3 main.py
```

**Поддерживаемая переменная:**
- `SAMBA_PASSWORD` или `AUTO_SETUP_SAMBA_PASSWORD` - для пароля Samba пользователя

📖 [Подробная документация по переменным окружения](ENV_VARIABLES.md)

### Что происходит при запуске:

1. **🔍 Проверка требований**
   - Проверка прав суперпользователя (`pkexec` / `sudo`)
   - Проверка наличия необходимых файлов
   - Надежное определение непривилегированного пользователя (`PKEXEC_UID` / `SUDO_USER`)

2. **📦 Установка пакетов (Шаг 1)**
   - Обновление системы через pacman
   - Установка paru (если отсутствует)
   - Установка AUR и официальных пакетов через paru от имени пользователя

3. **🖥️ Настройка Samba (Шаг 2)**
   - Создание директорий
   - Настройка прав доступа
   - Конфигурация smb.conf
   - Добавление пользователя в Samba
   - Запуск и настройка служб
   - Тестирование работоспособности
   - Настройка файрвола

5. **📊 Итоговый отчёт**
   - Статистика выполненных операций
   - Информация о доступных ресурсах
   - Рекомендации по дальнейшим действиям

## 🔧 Настройка пакетов

### Редактирование списков пакетов

Перед запуском вы можете изменить списки устанавливаемых пакетов в файле `code/install.py`:

```python
# Пакеты для установки через paru (официальные репозитории + AUR)
PARU_PACKAGES = [
    'google-chrome',
    'telegram-desktop',
    'visual-studio-code-bin',
    # ... добавьте свои пакеты
]
```

### Настройка Samba ресурсов

Для изменения общих папок Samba отредактируйте файл `code/samba_auto_setup.py` в функции `step_2_configure_smb()`.

## ❗ Устранение неполадок

### Ошибка импорта модулей
```bash
❌ Ошибка импорта модулей: No module named 'install'
```
**Решение:** Убедитесь, что файлы находятся в папке `code/`

### Ошибка прав доступа
```bash
❌ Этот скрипт требует прав суперпользователя
```
**Решение:** Запустите с `sudo`

### Частичная неудача
```bash
⚠️  ЧАСТИЧНЫЙ УСПЕХ (1/2 шагов)
```
**Решение:** Проверьте логи, запустите проблемные шаги отдельно

### Проблемы с сетью при установке пакетов
**Решение:** Перезапустите скрипт, проблемные пакеты можно доустановить вручную
