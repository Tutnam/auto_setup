# 🚀 Auto Setup - Автоматическая настройка CachyOS/Arch Linux

Автоматизированная установка пакетов и настройка Samba сервера одной командой.

## ✨ Возможности

- **📦 Установка пакетов** - автоматическая установка через yay (AUR) и pacman
- **🖥️ Настройка Samba** - полная настройка сервера с общими папками
- **🧪 Тестирование** - проверка работоспособности всех компонентов

## 🚀 Использование

```bash
# Клонировать репозиторий
git clone <repository-url> auto_setup
cd auto_setup

# Запустить полную настройку (РЕКОМЕНДУЕТСЯ)
sudo python3 main.py
```

**Это всё!** Скрипт автоматически:
1. Установит все необходимые пакеты 
2. Настроит Samba сервер
3. Протестирует работоспособность

## 📁 Структура проекта

```
auto_setup/
├── main.py                 # 🌟 Главный скрипт
└── code/
    ├── install.py          # 📦 Установщик пакетов
    └── samba_auto_setup.py # 🖥️ Настройка Samba
```

## ⚙️ Настройка под себя

### Изменение списков пакетов

Отредактируйте `code/install.py`:

```python
# Пакеты из AUR (через yay)
YAY_PACKAGES = [
    'yandex-music',
    'pycharm-professional',
    'google-chrome',
    # Добавьте свои пакеты
]

# Пакеты из официальных репозиториев
PACMAN_PACKAGES = [
    'samba',
    'vlc',
    'telegram-desktop', 
    # Добавьте свои пакеты
]
```

### Настройка Samba ресурсов

Отредактируйте конфигурацию в `code/samba_auto_setup.py` в функции `step_2_configure_smb()`.

## 📋 Системные требования

- **ОС:** CachyOS/Arch Linux (основная поддержка)
- **Python:** 3.6+
- **Права:** sudo доступ
- **Интернет:** для загрузки пакетов

## 🎯 Альтернативные способы запуска

```bash
# Только установка пакетов
sudo python3 code/install.py

# Только настройка Samba  
sudo python3 code/samba_auto_setup.py
```

### Проверка статуса Samba
```bash

sudo testparm
```

### Проверка установленных пакетов
```bash
yay -Q | grep -E "(chrome|yandex|samba)"
```

### Ошибки прав доступа

## 🔧 Особенности

- **Единый пароль:** sudo пароль автоматически используется для всех операций, включая настройку Samba пользователя
- **Безопасность:** пароли не сохраняются, временные файлы очищаются
- **Совместимость:** оптимизирован для CachyOS/Arch Linux
- **Гибкость:** можно запускать компоненты отдельно
